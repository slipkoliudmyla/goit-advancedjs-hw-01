# goit-advancedjs-hw-01

Homework for the GoIT course "Advanced JavaScript and TypeScript", topic 2 "Code modularity".

- `1-gallery.html` — image gallery built with [SimpleLightbox](https://simplelightbox.js.org/)
- `2-form.html` — feedback form that keeps its state in `localStorage`

## Run locally

```bash
npm install
npm run dev
```
